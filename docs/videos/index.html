📋 MapReduce Viva & Practical Exam Commands (Shown in Video 2)

Track A: The Fast 1-Line Shortcut Speed Run

Executes HDFS directory setup, uploads text, runs YARN MapReduce, and prints the top 25 word frequencies.

./run-wordcount.sh sample_input.txt

Track B: Step-by-Step 1-by-1 Manual Commands (for Viva & Practical Exams):

  • Step 1: Check running daemons in terminal:

    jps

  • Step 2: Create an HDFS input directory:

    hdfs dfs -mkdir -p /my_lab/input

  • Step 3: Upload local text file to HDFS:

    hdfs dfs -put -f sample_input.txt /my_lab/input/

  • Step 4: Verify file existence in HDFS:

    hdfs dfs -ls /my_lab/input

  • Step 5: Execute the MapReduce JAR manually:

    hadoop jar $HADOOP_HOME/share/hadoop/mapreduce/hadoop-mapreduce-examples-*.jar wordcount /my_lab/input /my_lab/output

  • Step 6: Inspect MapReduce output block in HDFS:

    hdfs dfs -cat /my_lab/output/part-r-00000 | head -n 25

  • Step 7: Download output back to local computer:

    hdfs dfs -get /my_lab/output/part-r-00000 ./lab_results.txt
