Installation Commands

Windows (PowerShell)

Checks for Git & WSL, saves to Desktop, and installs Hadoop.

irm https://raw.githubusercontent.com/fridayslifes/Hadoop/main/setup.ps1 | iex
Linux / WSL Terminal

One-line automated installation for Linux.

curl -sSL https://raw.githubusercontent.com/fridayslifes/Hadoop/main/install.sh | bash
Start Hadoop

Starts HDFS and YARN daemons in foreground.

ran-hadoop

MapReduce Commands

Method 1: Shortcut Script
./run-wordcount.sh sample_input.txt
Method 2: Manual Commands Step-by-Step

  • Step 1: Check daemons

    jps

  • Step 2: Create HDFS directory

    hdfs dfs -mkdir -p /my_data/input

  • Step 3: Upload input file

    hdfs dfs -put -f sample_input.txt /my_data/input/

  • Step 4: Run MapReduce jar

    hadoop jar $HADOOP_HOME/share/hadoop/mapreduce/hadoop-mapreduce-examples-*.jar wordcount /my_data/input /my_data/output

  • Step 5: View results

    hdfs dfs -cat /my_data/output/part-r-00000 | head -n 25
